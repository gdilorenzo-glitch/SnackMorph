# Prospective independent validation protocol (draft; approve before running held-out data)
## Synthetic JPEG
100 files from 20 geometry groups with five variants each. Development J01–J08; test J09–J20. Each group contains 36 different objects (720 unique geometries overall, 3,600 observations across variants). Input JPEG is separate from labels and reference CSVs. Independent analytic arc and diameter, spatial scale, four-position ED and 23-position width profile; model Pk and Le only on symmetric positive flat-top cases. Include constant/asymmetric shapes as negative controls for model suitability. Measure width with supplied mm/pixel, not calibrated against the target diameter. Match predicted masks to truth labels by maximum overlap with one-to-one assignment, log unmatched/extra objects. Report Dice, IoU, count and cell assignment, ED, length and width errors; profile direction may require alignment using known axis orientation and a predeclared reversal rule. For ideal uniform colour use uncorrected Lab against nominal sRGB/D65; evaluate colour gradient windows with an independently computed window reference or report pointwise comparisons as approximate. Degraded cases measure robustness, not camera accuracy.
## Synthetic VOX
30 files from 15 geometric groups (five development V01–V05, ten test V06–V15). Compare input read against XML and raw shape. First use known ROI to isolate segmentation and descriptor error, then evaluate automatic ROI against independent reference. Report ROI Dice, solid/pore Dice, total/open/closed porosity error in percentage points under identical 6-connectivity, volume error, component count for isolated pores (not equivalent to arbitrary watershed labels), local thickness against nominal ideal sphere/cylinder/lamella interior dimensions where valid. Do not claim absolute ground truth for MIL anisotropy, Euler or local thickness in a complex network; use simpler dedicated geometries or independent reference implementations first. Report geometry direction only as a qualitative orientation target. For resolution comparisons, resample truth on matching grid or define an analytical reference for each resolution, record phase/crop and distinguish partial-volume effects. The simulated support is a simplified stress test. These geometries do not constitute a factorial design over every nominal target level or scanner model.
## Experimental JPEG (not yet acquired)
Proposed 30 independent specimens, 3 lots x 10, three photographic acquisitions each (90 images, nested within specimen). Independent calibrated scale target in the plane, caliper measurements at matched projected positions by an operator blinded to software outputs (2 repeats), independent trace for curved length, independently traced masks by two operators for a subset. Preserve original files, acquisition settings, calibration uncertainty and IDs. Compare nominal expansion indices calculated with the same definitions. For colour photograph a physical calibrated chart under identical lighting; reserve validation patches independent of calibration and obtain spectrophotometer/colourimeter readings on corresponding snack regions if available. Record illuminant, observer, geometry, instrument repeatability; do not conflate chart accuracy with snack surface accuracy.
## Experimental VOX (not yet acquired)
Select 4–6 held-out specimens not used to tune parameters and a physical phantom with independently metrologically measured holes, channels and walls; ideally repeat scans. Independent operators annotate a pre-specified set of slices/ROIs, or full 3D masks if feasible. Fiji/ImageJ and BoneJ intersoftware comparison uses same voxel size, masks and mathematical definitions; agreement is not absolute accuracy. Preserve VOX, XML, reference masks and physical measurements, and instrument uncertainty separately. Do not treat slices/pores as independent specimen replicates. All samples are independent unless documented repeat acquisitions of one specimen.
## Analysis plan
Freeze commit hash, settings, split, calibration, matching rule and metric-specific acceptance thresholds before opening test results. Proposed thresholds must be agreed based on intended use and measurement uncertainty, not tuned retrospectively. Record failures and missing values, per specimen/group distributions, signed bias, MAE, RMSE, relative errors only for nonzero targets, agreement plots and cluster-aware intervals; separate clean accuracy from stress-case robustness. Use Bland–Altman only for genuinely paired quantities with appropriate repeated-measure treatment. Report results by family and acquisition condition. No validation claim until independent benchmark measurements are compared. If test failures trigger tuning, obtain a new independently generated holdout. No test results are to be added to the manuscript before execution.
